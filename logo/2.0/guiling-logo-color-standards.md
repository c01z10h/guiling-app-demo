# 归零 Logo 2.0｜标准色规范

母版：`guiling-logo-primary.svg`

| 版本 | 色值 | 推荐用途 |
|---|---|---|
| 主渐变 | #123B4A → #247C78 → #87D3C3 | 品牌主视觉、启动页、官网与重点传播物料 |
| 品牌青绿 | #247C78 | 常规单色 Logo、小尺寸图标、UI 导航 |
| 深海墨色 | #123B4A | 浅色背景、正式文件、印刷与商务场景 |
| 薄荷辅助色 | #87D3C3 | 深色背景上的柔和表达及辅助视觉 |
| 标准黑 | #111111 | 单色制版、烫印、压印、传真等受限工艺 |
| 反白 | #FFFFFF | 深色或图片背景；背景需保证足够对比度 |
| 夜光渐变 | #38A7B6 → #5AD7C8 → #D8FFF7 | 深色模式、数字屏幕与动态视觉 |

## 使用原则

- 优先使用主渐变版；小于 32 px 时优先使用品牌青绿单色版。
- 不改变渐变方向，不任意替换渐变节点，不添加描边、阴影或发光。
- 不拉伸、不旋转、不重新组合 Logo 的三个结构部分。
- 反白版本不得置于低对比度浅色背景上。
- 所有版本保留母版的原始视图框与路径比例，可直接互换使用。
