# 归零 APP UI 2.0｜界面设计说明

Figma 文件：https://www.figma.com/design/BvYr59EJrxrayVm822B1OY

## 一、设计定位

归零是一款服务年轻都市用户的冥想、呼吸与情绪复位 APP。视觉核心不是传统禅意或医疗健康，而是“从城市噪音回到自己的呼吸”：安静、轻盈、现代，同时保留适度的情绪温度。

正式 Logo 同时包含冥想人形、呼吸循环、无限符号与归零重启的含义。界面以同样的连续曲线、圆形轨道和循环动画作为视觉语言，使品牌标志与产品体验保持一致。

## 二、视觉思路

### 1. 深海青绿的沉浸感

- `#123B4A` 深海墨色：沉浸页面、核心文字、深色背景。
- `#247C78` 品牌青绿：主按钮、导航选中、关键操作。
- `#87D3C3` 呼吸薄荷：玻璃高光、呼吸光圈、完成反馈。
- `#DFF3EE` 泡沫白：浅色背景、卡片内部和柔光层。
- `#E6A187` 暖砂珊瑚：情绪提示和少量对比，避免全青绿色产生医疗感。

### 2. 毛玻璃不是装饰，而是信息层级

界面使用三层玻璃关系：环境色光斑形成空间背景；半透明内容卡片承载信息；白色高光描边和内阴影建立玻璃边缘。重要操作使用更实的品牌青绿，保证可读性与操作识别度。

### 3. 呼吸式排版节奏

大标题与卡片之间保留充足留白，圆形图形、轨道和柔光采用由大到小的嵌套结构，模拟“吸气—停留—呼气”。页面进入、呼吸环与按钮反馈使用缓慢、柔和的缓动，避免刺激感。

### 4. 年轻都市感

避免佛教符号堆叠和传统养生色彩，通过简洁英文标签、非对称光斑、半透明悬浮导航、横向内容卡片和轻量数据图表，建立更接近数字生活方式品牌的体验。

## 三、界面结构

Figma 文件包括 9 个核心状态：

1. 启动页：正式 Logo、品牌主张和夜光渐变。
2. 新手引导：三步价值说明与呼吸轨道视觉。
3. 首页：今日情绪、个性化练习、连续归零和内容推荐。
4. 发现：搜索、情绪分类、专题推荐和练习集合。
5. 轨迹：练习趋势、累计时长和一周节奏。
6. 我的：个人数据、提醒、声音、主题与产品信息。
7. 练习详情：内容介绍、收益标签和时长选择。
8. 呼吸练习：计时器、呼吸光圈、声音与播放控制。
9. 完成页：正向反馈、练后情绪记录和再次练习。

## 四、字体系统

- `DM Serif Display`：情绪化大标题与数据数字，增加编辑感和人文气质。
- `Manrope`：英文标签与界面信息，保持现代和清晰。
- `Noto Sans SC`：中文正文与操作文字，保证屏幕阅读质量。
- `JetBrains Mono`：计时器等精确数字，增强时间感和功能辨识。

字体通过 Google Fonts 引入。正式发布时应根据目标平台完成字体授权、字体包体积和离线策略复核。

## 六、素材来源与原创说明

- Logo：用户最终确认的归零 2.0 SVG 母版，位于 `logo/2.0/guiling-logo-primary.svg`。
- 页面结构与文案：来自项目内《Figma设计规划》《归零-完整项目规划》《PRD-归零》及当前 APP 实现。
- 图标：项目代码内原创线性 SVG 路径，没有使用第三方图标包。
- 情绪图形：使用操作系统原生 Emoji，实际跨平台发布时需考虑不同系统的呈现差异。
- 背景与视觉效果：全部由 CSS 渐变、透明度、描边、模糊和阴影生成。
- 未使用第三方摄影图片、插画图库、生成式图片或付费素材。

## 七、使用原则

- 主操作统一使用品牌青绿，不重新引入紫色作为主色。
- 暖砂珊瑚只承担情绪提示和局部对比，不大面积使用。
- 深色练习场景保证正文和控制按钮达到足够对比度。
- 不改变 Logo 的比例、渐变方向、结构开口和冥想人形关系。
- 小于 32 px 的 Logo 优先使用品牌青绿单色版，避免渐变细节损失。
