## 1. 产品概述

### 1.1 产品定义

**归零**是一款面向冥想初学者的轻量冥想 App。用户通过选择当前状态或可用时间，获得 3-15 分钟的引导练习推荐，完成练习后记录感受。

### 1.2 核心价值主张

> **随时归零，然后回来。** — 不是逃离，是暂停。坏情绪进来，清零，好状态出去。

### 1.3 目标平台

| 平台 | 版本 | 优先级 |
|------|------|--------|
| iOS | 16.0+ | P0 |
| Android | 13+ | P0 |

### 1.4 一句话介绍

一个不吵不闹的冥想 App。坏情绪进来，归零，好状态出去。

## 3. 用户故事

### Epic 1：核心归零路径（P0）

| ID | 用户故事 | 验收要点 |
|----|---------|---------|
| US-01 | 作为初学者，我希望能快速表达当前状态，以便获得适合我的练习推荐 | 8 个状态 Chip 全部可见，点击即选中，再次点击取消 |

## 4. 功能规格

### 4.1 首页（HomeScreen）

| 元素 | 规格 |
|------|------|
| **顶部栏** | 品牌名「归零」（Cormorant Garamond 24px）+ 设置图标按钮 |
| **问候语** | "今天也要归零"（13px, text/tertiary） |
| **状态 Chips** | 2 列 4 行，8 个选项：紧张焦虑/疲惫乏力/难以专注/烦躁不安/难以入眠/压力山大/迷茫不确定/想要保持 |
| **时长 Chips** | 横向滚动，4 个选项：3/5/10/15 分钟 |
| **推荐卡片** | 毛玻璃卡片，选中状态或时长后从下方滑入（0.35s）。内容：练习名 + 时长 + 简介 + 评分 + 开始按钮 |
| **连续打卡** | 7 个圆点，本周已完成高亮，今天有脉冲动画 |
| **底部导航** | 4 Tab：首页/探索/记录/我的 |

**交互规则**：
- 状态 Chip 和时长 Chip 可独立选择，互不依赖
- 任一选择后推荐卡片出现
- 取消所有选择后推荐卡片隐藏
- 点击推荐卡片 → 进入练习详情页

### 4.2 练习详情（DetailScreen）

| 元素 | 规格 |
|------|------|
| **顶部栏** | 返回按钮 + 收藏按钮 |
| **Hero** | 200px 高，渐变色背景，中央毛玻璃图标 |
| **标题** | Cormorant Garamond 24px |
| **元信息** | 时长 + 难度 + 评分 |
| **练习简介** | 15px 正文，行高 1.6 |
| **场景标签** | 只读 Chip，圆角全圆（pill） |
| **引导方式** | 说明文字 |
| **CTA** | 全宽主按钮「开始归零」，固定底部 |

### 4.3 冥想播放（PracticeScreen）

| 元素 | 规格 |
|------|------|
| **背景** | 渐变色（#e8e5de → #f7f5f0） |
| **计时器** | 240×240 SVG 环形，6px 宽度。剩余时间 JetBrains Mono 56px |
| **练习名** | Cormorant Garamond 20px |
| **引导文字** | 15px，居中，最大宽度 260px。随练习阶段切换 |
| **进度条** | 4px 高，240px 宽，圆角全圆 |
| **控制按钮** | 72×72 圆形播放/暂停按钮 + 结束练习文字按钮 |

**计时器逻辑**：
- 每秒递减，`stroke-dashoffset` 线性过渡 0.3s
- 归零时自动跳转完成页
- 暂停时保留当前进度
- 结束练习 → 以当前时长记录并跳转完成页

### 4.4 完成页（CompleteScreen）

| 元素 | 规格 |
|------|------|
| **完成图标** | 80×80 圆，calm 绿背景 + 白色 ✓ |

| **副标题** | "你练习了 X 分钟" |
| **感受选择** | 5 级 emoji：😣😐🙂😊☺️，默认选中 ☺️ |
| **连续打卡** | 更新后的打卡天数 |
| **操作** | 「再归零一次」（主按钮）+「回到首页」（幽灵按钮） |

### 4.5 探索页（ExploreScreen）

| 元素 | 规格 |

| **搜索栏** | 占位文字"搜索练习、场景或引导者…"，非功能入口（MVP） |
| **分类 Chips** | 横向滚动：全部/晨间唤醒/提升专注/助眠放松/缓解压力/呼吸练习 |
| **练习列表** | 圆角卡片列表，每项：图标 + 标题 + 元信息 + 箭头 |

### 4.6 记录页（HistoryScreen）

### 4.8 提醒设置（ReminderScreen）

| 元素 | 规格 |

| **周末提醒** | Toggle 开关 |
| **连续打卡提醒** | Toggle 开关 |

### 4.9 启动页（SplashScreen）

| 元素 | 规格 |
|------|------|
| **品牌名** | "归零"（48px Cormorant Garamond） |
| **标语** | "随时归零，然后回来"（13px text/tertiary） |
| **加载动画** | 40px 宽 × 2px 高进度条，靛蓝灰填充从左到右循环 |
| **背景光晕** | 200px 圆形，accent/primary 6% opacity，呼吸缩放动画 4s |

### 4.10 新手引导（OnboardingScreen）

| 步骤 | 标题 | 描述 | emoji |
|------|------|------|-------|
| 1/3 | 表达你的状态 | 告诉归零你现在感觉怎么样——紧张、疲惫、还是难以专注。我们会为你找到最合适的练习。 | 😌 |
| 2/3 | 闭上眼睛，归零 | 选择一个练习，闭上眼睛，跟随声音引导。3到15分钟后，你会感到不一样——不需要任何经验。 | 🧘 |
| 3/3 | 每天归零一次 | 不追求连续打卡一百天。只要今天归零了，就够了。明天再说明天的。 | ✅ |

每步包含：160px 圆形插图 + 步数 + 标题 + 描述 + 进度点 + 「跳过」+「下一步/开始归零」

| 场景 | 预期行为 |
|------|---------|
| 首次打开 App | 展示启动页 → 新手引导 → 首页 |
| 非首次打开 | 展示启动页 → 首页 |
| 选择状态后切换 | 推荐内容实时更新 |

| 记录页无数据 | 展示空状态引导 |
| 网络断开 | 不影响核心功能（MVP 全本地） |

## 6. 非功能需求

### 6.1 性能

| 指标 | 目标 | 测量方法 |
|------|------|---------|
| 冷启动时间 | < 2s | App 启动到首页可交互 |
| 页面切换 | < 300ms | Navigation 转场完成 |
| 计时器精度 | ±100ms | 与系统时钟对比 |
| 安装包大小 | < 50MB (iOS) / < 30MB (Android) | App Store / APK 大小 |
| 列表滚动 | 60fps | FPS 监控 |
| 内存占用 | < 150MB | Xcode / Android Profiler |

### 6.2 可访问性

| 标准 | 要求 |
|------|------|
| 文字对比度 | WCAG AA（正文 ≥ 4.5:1） |
| 触控区域 | ≥ 44×44px |
| Focus ring | 可见且对比度 ≥ 3:1 |
| 动效降级 | `prefers-reduced-motion` 支持 |
| 语义化 | 正确使用 header/nav/main + ARIA 属性 |

### 6.3 兼容性

| 平台 | 最低版本 |
|------|---------|
| iOS | 16.0 |
| Android | 13.0 (API 33) |

### 6.4 隐私

| 要求 | 实现 |
|------|------|
| 练习数据 | 仅本地存储（MVP），用户可选择同步到 iCloud |
| 不收集 | 位置、通讯录、相册、麦克风（MVP 无语音输入） |
| 隐私政策 | App 内可访问 |
| 数据删除 | 设置中一键清除所有本地数据 |

## 10. 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| 用户首次体验后不再回来 | 高 | 高 | 新手引导突出"随时"定位；D1 推送"该归零了" |
| 冥想内容质量不足 | 中 | 高 | MVP 用 TTS 快速验证，v1.0 用真人录音 |
| 推荐不准 | 中 | 中 | MVP 用规则引擎覆盖 8 种场景；V2 用用户反馈优化 |
| iOS 审核被拒 | 低 | 高 | 隐私政策完善，不申请不必要的权限 |
| 竞品快速跟进 | 中 | 低 | 品牌差异化（"随时归零"的��具化定位难以复制） |
| 音频版权问题 | 低 | 中 | 自有版权录音 + 原创脚本 |
