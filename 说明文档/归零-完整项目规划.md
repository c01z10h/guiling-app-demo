## 1. 品牌策略

### 1.1 品牌核心

| 维度 | 定义 |
|------|------|
| **品牌名** | 归零（Zero In） |
| **品牌主张** | 随时归零，然后回来 |
| **一句话介绍** | 一个不吵不闹的冥想 App。坏情绪进来，归零，好状态出去 |
| **品牌人格** | 28 岁，平静但不冷淡，简短但不敷衍，不贩卖焦虑 |
| **品牌关键词** | 随时、归零、清空、回来、满电、重启、暂停、好状态 |

### 1.2 目标用户

| 维度 | 描述 |
|------|------|
| **年龄段** | 20-35 岁 |
| **人群** | 城市年轻人，工作节奏快，无系统冥想经验 |
| **场景** | 工作间隙、学习前、情绪紧张、睡前 |
| **痛点** | 不知道选什么内容、不愿面对复杂课程体系 |
| **心理模型** | "我只有 5 分钟，告诉我该做什么" |

### 1.3 竞品定位

| 竞品 | 定位 | 归零差异化 |
|------|------|-----------|
| Headspace | 轻松活泼 | 归零更冷静、更克制 |
| Calm | 直给平静 | 归零不承诺奇迹，只帮你暂停 |
| 潮汐 | 诗意自然 | 归零更都市、更干练 |
| Now 冥想 | 功能导向 | 归零有态度、有品牌人格 |

### 1.4 App Store 元数据

```
名称：归零 - 随时归零，然后回来
副标题：坏情绪归零，好状态回来
关键词：冥想、呼吸、放松、专注、睡眠、正念、减压、情绪管理
```

### 1.5 视觉符号

- **主符号**：圆形空隙（不完整的圆，缺口暗示"归"的路径）
- **辅助符号**：`00:00`（计时器归零 = 练习开始）
- **品牌色**：靛蓝灰 `#5b6e7a` + 暖灰白 `#f7f5f0` + 深灰黑 `#2a2824`

> 详见：`BrandNaming.md`

## 2. 产品功能架构

### 2.1 功能全景图

```
归零 App
├── 1. 首页（核心路径入口）
│   ├── 状态选择（8 种预设状态 Chip）
│   ├── 时长快捷选择（3/5/10/15 分钟）
│   ├── 智能推荐卡片（玻璃卡片，选中状态后浮现）
│   └── 连续打卡指示器
│
├── 2. 练习详情
│   ├── 练习名称 + 图标 + 难度
│   ├── 练习简介
│   ├── 适合场景标签
│   ├── 引导方式说明
│   └── 开始练习 CTA
│
├── 3. 冥想播放
│   ├── 环形倒计时器（SVG 动画）
│   ├── 进度条
│   ├── 播放/暂停控制
│   ├── 引导文字（实时切换）
│   ├── 背景渐变（练习页专用）
│   └── 结束练习
│
├── 4. 完成页
│   ├── 完成动画
│   ├── 感受记录（5 级情绪选择）
│   ├── 连续打卡更新
│   └── 再归零 / 回首页
│
├── 5. 探索（Tab 2）
│   ├── 搜索入口
│   ├── 分类筛选（晨间/专注/助眠/减压/呼吸）
│   ├── 练习列表
│   └── → 练习详情
│
├── 6. 记录（Tab 3）
│   ├── 统计摘要（总练习/总分钟/连续天）
│   ├── 月历热力图
│   └── 空状态引导
│
├── 7. 我的（Tab 4）
│   ├── 个人信息
│   ├── 提醒设置 → 提醒详情页
│   ├── 隐私与数据
│   ├── 关于归零
│   └── 反馈与建议
│
├── 8. 系统级
│   ├── 启动页（品牌 Logo + 呼吸动画）
│   ├── 新手引导（3 步：表达状态 → 闭眼归零 → 每天一次）
│   ├── 推送提醒（"该归零了"）
│   └── 连续打卡彩蛋
```

### 2.2 功能优先级

| 优先级 | 功能 | 理由 |
|--------|------|------|
| **P0** | 首页状态选择 + 推荐 + 练习播放 + 完成记录 | 核心路径，MVP 必须 |
| **P0** | 启动页 + 新手引导 | 首次体验决定留存 |
| **P1** | 探索页（分类+搜索） | 非状态驱动的自由浏览 |
| **P1** | 记录页（统计+日历） | 成就感驱动留存 |
| **P1** | 我的页 + 提醒设置 | 基本设置 |
| **P2** | 音频引导（真人录音） | MVP 可用 TTS 替代 |
| **P2** | Apple Watch 伴侣 App | 触觉反馈呼吸引导 |
| **P3** | 社交分享（归零卡片） | 增长手段 |
| **P3** | 个性化推荐算法 | MVP 用规则引擎 |

## 3. 用户流程与信息架构

## 4. UI 设计系统

### 4.1 设计系统名称

**「禅意玻璃」** — 日式禅意的留白哲学 × 液态玻璃的柔和层次

### 4.2 配色方案

```
主背景
  --bg-primary:    #f7f5f0   暖灰白（页面底色）
  --bg-secondary:  #f0ede6   次级背景（卡片底）
  --bg-tertiary:   #e8e5de   三级背景（分隔区）

文字
  --text-primary:    #2a2824   主文字（近黑不刺眼）
  --text-secondary:  #6b6863   次要文字
  --text-tertiary:   #9c9993   辅助文字/占位符
  --text-on-accent:  #ffffff   强调色上文字

强调色
  --accent-primary:  #5b6e7a   靛蓝灰（主强调，CTA、选中态）
  --accent-calm:     #7a9a8a   冷静绿（完成、平静状态）
  --accent-warm:     #b89585   暖调（情感标记，低频使用）
  --accent-soft:     #b8b0a4   柔和中性（分隔线）

毛玻璃
  --glass-layer:  rgba(247,245,240,0.65)
  --glass-border: rgba(255,255,255,0.5)
  backdrop-filter: blur(20px) saturate(130%)

渐变
  --gradient-calm:   160deg #e8e5de → #f0ede6 → #f7f5f0  （练习页背景）
  --gradient-accent: 135deg #5b6e7a → #7a9a8a            （CTA 按钮）
```

## 5. UX 交互规范

### 5.1 动效系统

| 类型 | 时长 | 缓动 | 说明 |
|------|------|------|------|
| 微交互（hover/active） | 0.2s | `cubic-bezier(0.4,0,0.2,1)` | 按钮、Chip、列表项 |
| 页面转场 | 0.3s | 同上 | fadeIn + slideUp(8px) |
| 卡片浮现 | 0.35s | 同上 | 推荐卡片选中后出现 |
| 计时器 | 0.3s linear | — | stroke-dashoffset 过渡 |
| 呼吸动画 | 4s ease-in-out | — | 启动页光晕脉冲 |

**动效偏好**：`@media (prefers-reduced-motion: reduce)` 全局禁用

### 5.2 触控规范

| 元素 | 最小触控区域 |
|------|------------|
| 按钮 | 44×44px |
| 图标按钮 | 44×44px |
| StateChip | 整卡可点，最小 56px 高 |
| 列表项 | 整行可点，最小 52px 高 |
| 底部导航项 | 44px 高 |

### 5.3 反馈机制

| 场景 | 反馈 |
|------|------|
| 按钮点击 | `transform: scale(0.97)` 即时反馈 |
| 状态选择 | 选中态边框 + 背景色变化 |
| 推荐更新 | 卡片从透明滑入（0.35s） |
| 计时器 | 环形进度 + 进度条双重反馈，每秒更新 |
| 练习完成 | 自动跳转完成页 + 完成图标 |
| 感受记录 | 选中态缩放 1.1 + 外环高亮 |

### 5.4 空状态设计

| 页面 | 空状态文案 | 行动引导 |
|------|-----------|---------|
| 记录页 | "还没有归零记录" | "开始归零"按钮 → 首页 |
| 探索搜索结果 | "没有找到相关练习" | "试试其他关键词" |
| 首页推荐 | "今天想归零吗？" | 引导选择状态 |

### 5.5 文案语气

| 原则 | 示例 |
|------|------|
| **三字以内优先** | "该归零了" 而非 "是时候进行冥想了" |
| **不说"您"** | "你现在感觉怎么样？" |
| **不感叹** | 不用感叹号、"太棒了""厉害了" |
| **不煽情** | 不暗示用户需要被治愈 |
| **品牌动词化** | "归零一下" → 可随口说出的日常表达 |

### 5.6 可访问性

| 标准 | 状态 |
|------|------|
| 文字对比度 WCAG AA | ✅ 正文 ≥4.5:1（实际 ~12.5:1） |
| Focus ring 可见 | ✅ 2px `--accent-primary` outline |
| 语义化 HTML | ✅ header/nav/main + ARIA roles |
| prefers-reduced-motion | ✅ 已实现 |
| 键盘可达 | ✅ Space 键切换播放/暂停 |

## 7. 技术栈与开发建议

### 7.1 推荐技术栈

| 层 | 推荐方案 | 备选方案 |
|----|---------|---------|
| **跨平台框架** | React Native + Expo | Flutter |
| **导航** | React Navigation (Stack + Bottom Tabs) | Expo Router |
| **状态管理** | Zustand（轻量） | Redux Toolkit |
| **动画** | react-native-reanimated + react-native-svg | Lottie |
| **音频** | expo-av | react-native-track-player |
| **推送** | Expo Notifications | Firebase Cloud Messaging |
| **存储** | AsyncStorage（本地）+ Supabase（云端） | MMKV + Firebase |
| **字体** | expo-font（Google Fonts 加载） | — |

### 7.2 核心模块技术方案

| 模块 | 方案 |
|------|------|
| **推荐引擎** | MVP：规则引擎（if-else 映射表）。V2：协同过滤 |
| **环形计时器** | react-native-svg Circle + stroke-dashoffset 动画 |
| **毛玻璃效果** | expo-blur（BlurView）或 @react-native-community/blur |
| **音频引导** | 预录制 .mp3 文件，expo-av 播放，定时器同步引导文字 |
| **日历热力图** | react-native-svg 自定义绘制或 react-native-calendar-heatmap |
| **连续打卡** | AsyncStorage 本地记录 + 云端同步 |

### 7.3 性能指标

| 指标 | 目标 |
|------|------|
| 冷启动时间 | < 2s |
| 页面切换 | < 300ms（60fps） |
| 计时器精度 | ±100ms |
| 安装包大小 | < 50MB（iOS）/ < 30MB（Android） |

## 附录 A：设计决策记录

| 决策 | 选项 | 选择 | 理由 |
|------|------|------|------|
| 美学方向 | 10 个模板 | 日式禅意 × 液态玻璃 | 留白哲学 + 现代质感，与「归零」调性一致 |
| 首页布局 | 3 变体 | 变体 A「垂直呼吸」 | 单列流、Chips 全可见、推荐卡片响应式浮现 |
| 练习页布局 | 3 变体 | 变体 C「大留白」 | 极致克制，让用户真正沉浸在练习中 |
| App 名称 | 5 候选 | 「归零」 | 动词化、有态度、与核心交互（计时器归零）天然绑定 |
| 强调色 | 多种 | 靛蓝灰 `#5b6e7a` | 冷静理性，降低朱红饱和度避免"赤陶橙"审美惯性 |
