# 归零 2.0

基于《Figma设计规划.md》及选定的 Dribbble 玻璃拟态参考，重新设计的移动端 Web 原型。项目不依赖构建工具，可直接由任意静态服务器运行。

```powershell
python -m http.server 4173
```

浏览器访问 `http://localhost:4173`。

核心流程：启动页 → 三步引导 → 今日状态仪表盘 → 练习详情与时长选择 → 沉浸式计时 → 完成反馈。

主要页面：

- 今天：情绪记录、快速归零、连续练习与横向内容推荐
- 发现：搜索、场景分类、编辑精选与练习合集
- 轨迹：深色数据图表、本月统计与每周节奏
- 我的：个人数据、提醒、声音和外观设置

当前入口使用 `app-v3.js` 与 `app-v3.css`；旧版文件保留用于设计迭代对照。
